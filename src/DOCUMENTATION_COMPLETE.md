## 🎯 Organization Principle

### Module-Centric Structure
```
docs/
├── {framework-area}/          [Category: Framework, Architecture, Modules, Development, Tools]
│   ├── INDEX.md               [Navigation hub for category]
│   └── {document-type}/       [Type: Guides, Reports, Setup, Quickstart]
│       ├── INDEX.md           [Navigation hub for type]
│       └── {documents}        [Actual documentation files]
```

### Document Types

| Type | Purpose | Location |
|------|---------|----------|
| **Guides** | How-to, learning, reference | `docs/{category}/guides/` |
| **Reports** | Analysis, status, reviews | `docs/{category}/reports/` |
| **Setup** | Installation, configuration | `docs/{category}/setup/` |
| **Quickstart** | Quick references | `docs/framework/quickstart/` |
